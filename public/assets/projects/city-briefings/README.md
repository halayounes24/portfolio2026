# city-briefings

Assets for **City Briefings** (slug `city-briefings` in `src/projects.ts`).

- `cover.webp` — cover image (project page header)
- `01.webp`, `02.gif`, `03.gif` — story images, in the order they appear
- `cover-thumb.webp` — (optional) small version that follows the cursor on the landing page

See `public/assets/README.md` for naming and size guidelines.
