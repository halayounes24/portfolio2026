# loccitane

Assets for **L'Occitane En Provence** (slug `loccitane` in `src/projects.ts`).

- `cover.webp` — cover image (project page header), 2400px wide
- `cover-thumb.webp` — small version (800px) that follows the cursor when
  hovering the project on the landing page
- `01.webp`, `02.webp`, … — story images, in the order they appear (not added yet)

See `public/assets/README.md` for naming and size guidelines.
